# Plannetary 2.1.5

## Auditoria e limpeza

- Removidos componentes legados sem referências ativas.
- Removida textura local sem uso.
- Removido proxy JPL sem consumidor ativo.
- Removidos trechos de código morto da renderização 3D.
- Reduzido o CSS removendo comentários históricos e regras exatamente duplicadas.
- Otimizado o carregamento das texturas dos satélites e removida uma camada redundante de nuvens da Terra.
- Corrigida a atualização periódica dos eventos orbitais enquanto a experiência lunar está aberta.
- Fixadas as versões diretas de React, React DOM, Vite, plugin React e Three.js.
- Revisada a estrutura de interação das experiências 3D e dos dados de satélites.
