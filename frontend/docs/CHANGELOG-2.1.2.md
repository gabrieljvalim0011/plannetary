# Plannetary 2.1.2

## Terra — refinamento visual 3D

- Reequilibrada a iluminação da Terra para revelar continentes e oceanos em vez de deixar grande parte do globo subexposta.
- Adicionada uma camada sutil de nuvens sobre a superfície para dar profundidade ao modelo.
- A camada de nuvens gira mais lentamente que a superfície para criar uma separação visual natural.
- Mantidas as interações, zoom e renderização otimizada.
