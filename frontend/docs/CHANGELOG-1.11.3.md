# Plannetary 1.11.3

## Seletor de planetas
- Retornado o formato vertical/orbital usado anteriormente.
- A roda do mouse continua avançando um planeta por vez, sem scrollbar visual.
- O planeta selecionado fica apenas ligeiramente afastado e ampliado, reduzindo a sensação de efeito exagerado.
- Transição do trilho refinada para manter o foco estável no planeta selecionado.
- Experiência mobile mantém seleção horizontal.

## Saturno
- Substituída a URL instável da NASA por uma mídia quadrada estável do Cassini hospedada no Wikimedia Commons.
- A miniatura de Saturno deixou de usar máscara/círculo que cortava os anéis.
- Removido qualquer anel desenhado por CSS sobre a fotografia real.
- Imagens do planeta selecionado recebem prioridade de carregamento.

## Revisão
- Mantida a arquitetura da 1.11.2.
- Nenhuma funcionalidade lunar foi removida.
