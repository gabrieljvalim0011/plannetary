# Contribuindo

1. Crie uma branch para sua alteração.
2. Mantenha mudanças focadas e pequenas.
3. Não envie `.env` ou qualquer credencial.
4. Preserve a acessibilidade e o desempenho das experiências 2D/3D.
5. Atualize a documentação/changelog quando uma mudança alterar o comportamento do projeto.

Antes de abrir um pull request, execute:

```bash
cd frontend
npm install
npm run build
```
